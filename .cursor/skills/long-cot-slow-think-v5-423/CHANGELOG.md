# Changelog

- **v4.2.0 (2026-04-23)**：明确**模型人格与立场**：以**设计师助手**视角陪跑与专业补充，不替代用户思考与决策。输出约定调整为**纯文本（.txt）** 交付。新增硬性要求：**链式思维（CoT）** 所用语言与 **query / 代码** 一致（query-code 同语种，避免中英混用错位）。

- **v4.1.0 (2026-04-21)**：引入**推理质量三大准则**作为贯穿 `<think>` 全过程的写作指南——自适应粒度组织（Optimal Structural Organization，关键节点深度展开、简单节点保持简洁）、渐进式认知支架（Effective Cognitive Scaffolding，渐进引入概念、显化 key insight、主动搭桥）、高频严格验证（Rigorous Verification，即产即验 + 交叉校验 + 轻量自查句散布全文）；将原 Backtracking/Verification 两类认知步骤重新定位为三大准则下的"带信号词显式落地形式"；Verification 表述由"在若干维度完成后"改为高频散布以对齐指南；`长度与深度` 与 `质量检查清单` 新增 3 条对应硬性指标（自适应粒度、≥2 处 key insight、≥4 处轻量即时自查句）；front matter description 同步补充三大准则表述。

- **v3.0.0 (2026-04-14)**：重构为单样本 + 11 维度完整推理模式；移除多样本/锚点分拣架构；`<redacted_thinking>` 改为按需求分析→视觉主题→配色→排版→组件→布局→深度→宜忌→响应式→交互→特效 11 个维度顺序推进；引入 Backtracking（跨维度回溯修正）和 Verification（显式自查验证）两种认知步骤类型；输出改为单条 JSONL，代码改为完整 index.html。

- **v2.0.0 (2026-04-03)**：重构为设计决策导向的多样本合成；必选锚点改为视觉方向/配色/版式/功能边界。

- **v1.0.0**：初始版本，聚焦技术实现决策（框架选型/状态管理等）的因果链合成。
