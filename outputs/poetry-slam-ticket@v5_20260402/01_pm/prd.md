# International Collaborative Poetry Slam — PRD

## 核心问题定义

这个产品帮助**文学爱好者与潜在观众**在**活动前信息获取阶段**解决"是否值得前往、如何购票"的决策问题，让他们能够在一个优雅的数字票务页面上完成活动了解 → 定价参考 → 注册报名的完整流程。

---

## 用户与场景分析

**用户类型**
- 主要：文学爱好者、诗歌从业者、创意艺术圈层受众（25–50 岁）
- 次要：企业赞助商代表、媒体记者
- 三级：偶然发现的泛文艺受众

**使用场景**
- 通过社交媒体或邮件分享链接，首次打开页面
- 在手机或桌面快速扫描活动亮点，决定是否深入阅读
- 对比票价后点击注册链接

**痛点**
- 传统活动页信息散乱，难以快速抓住关键信息（时间、地点、价格）
- 价格不透明导致跳出
- 页面缺乏仪式感，不能传达诗歌活动本身的文化气质

**目标结果**
- 用户在 30 秒内完成"想去 → 知道多少钱 → 点击报名"的完整判断链
- 页面传递高雅文化活动的氛围，产生对活动本身的期待感

---

## 设计意图

- **情绪目标**：打开页面时感受到文化底蕴与仪式感；使用过程保持安静、专注、期待的情绪基调
- **信息密度**：medium — 有足够内容支撑决策，但不杂乱
- **交互深度**：moderate — hover 效果、平滑滚动、票价表格高亮，不需要复杂状态机
- **视觉信任感**：premium — 传达活动品质，不能有广告感，需要真实的文化气质

## 功能契约

### Must Deliver（M）

| ID | 功能 | 验收条件 | 失败条件 | 表现力目标 |
|----|------|---------|---------|-----------|
| M01 | 活动标题首屏展示 | 页面加载后无需滚动即可看到完整活动名称、日期、地点 | 标题被截断或在首屏需要滚动才能看到 | 大字标题 + 仪式感入场动画，字体衬线体，配色温暖庄重 |
| M02 | 时间与地点双栏展示 | 日期/时间 和 场馆信息分左右两栏并列呈现，信息完整 | 两项信息堆叠或混淆，无法一眼区分 | 图标 + 排版层级，hover 时轻微上浮效果 |
| M03 | 活动描述段落 | 完整展示活动说明文字，段落可读性高 | 文字溢出或不可读 | 优雅衬线体正文，首字下沉或引言样式增强仪式感 |
| M04 | 票价对照表 | 三档票价（Early Bird/General/VIP）完整展示，包含票名与价格 | 任意一档缺失或价格错误 | 表格带交替底纹，hover 行高亮，VIP 行视觉强调 |
| M05 | 注册 CTA 按钮 | 按钮可点击并跳转至 registration_link，按钮文案清晰 | 链接失效或按钮不可点击 | 暖色系强调按钮，hover 时有色彩过渡动效 |
| M06 | 页脚联系信息 | 邮箱和电话可见，赞助商列表完整 | 联系信息缺失或赞助商列表不完整 | 低调衬托，字号小但排版精细 |

### Should Deliver（S）

| ID | 功能 | 理想形态 | 降级底线 |
|----|------|---------|---------|
| S01 | 评奖标准展示 | 带图表或视觉化权重展示 5 项评分维度 | 文字列表或简单表格 |
| S02 | 奖项信息展示 | 卡片式三等奖位呈现，视觉层级清晰 | 纯文字列表 |
| S03 | 滚动入场动画 | 各区块在进入视口时淡入上浮 | 无动画但排版完整 |
| S04 | 移动端响应式 | 双栏在手机折叠为单栏，表格水平可滚动 | 桌面布局缩放但不崩溃 |

### Excluded（X）

| ID | 功能 | 排除原因 |
|----|------|---------|
| X01 | 用户登录/账号系统 | 注册通过外部 Eventbrite 完成，本页只提供跳转 |
| X02 | 多语言切换 | 本次为单语言原型，扩展可在后续版本实现 |
| X03 | 实时余票查询 | 需要后端 API，超出静态页范围 |

## 内容意图地图（IA）

### Hero 首屏
- **意图**：让用户在最短时间内建立"这是什么、在哪里、什么时候"的基本认知，并激发期待感
- **优先级**：P0
- **必须包含**：活动名称、活动日期、地点城市、简短情绪标语（可从 description 提取）
- **创作自由度**：fully-open
- **关联契约**：M01

### 时间与地点区块
- **意图**：让用户快速确认日程安排是否与自身计划匹配
- **优先级**：P0
- **必须包含**：完整日期（October 21, 2023）、开始/结束时间（6:00 PM–9:00 PM）、完整场馆名称（Teatro Real, Madrid, Spain）
- **创作自由度**：content-fixed-layout-free
- **关联契约**：M02

### 活动描述区块
- **意图**：让用户了解活动内容与体验，强化参与意愿
- **优先级**：P0
- **必须包含**：原始 description 段落完整呈现
- **创作自由度**：content-fixed-layout-free
- **关联契约**：M03

### 票价表格区块
- **意图**：让用户完成价格判断，消除购票顾虑
- **优先级**：P0
- **必须包含**：Early Bird €15 / General Admission €25 / VIP €50，配套票种描述（可短文案补充）
- **创作自由度**：content-fixed-layout-free
- **关联契约**：M04

### 注册 CTA 区块
- **意图**：把意向转化为行动
- **优先级**：P0
- **必须包含**：注册按钮 + 链接指向 eventbrite URL，可附一句召唤语
- **创作自由度**：fully-open
- **关联契约**：M05

### 评奖标准区块
- **意图**：让参赛诗人了解评分维度，增加活动公信力
- **优先级**：P1
- **必须包含**：5 项标准名称 + 分值（originality 20、collaboration 20、performance 30、language usage 20、audience engagement 10）
- **创作自由度**：fully-open
- **关联契约**：S01

### 奖项区块
- **意图**：激励参赛者，提升活动吸引力
- **优先级**：P1
- **必须包含**：1–3 名奖项、奖金、合作出版/杂志/工作坊权益
- **创作自由度**：fully-open
- **关联契约**：S02

### 页脚
- **意图**：为有进一步疑问的用户提供联系出口，同时完成品牌背书
- **优先级**：P1
- **必须包含**：email (info@internationalpoetryslam.com)、phone (+34 91 123 4567)、三家赞助商（Editorial Anagrama / Poesía Digital / Fundación Loewe）
- **创作自由度**：content-fixed-layout-free
- **关联契约**：M06

## 响应式优先级

**balanced**（桌面与移动同等重要）

- 桌面（≥1024px）：内容区居中，最大宽度 860px，双栏信息区
- 平板（768–1023px）：保持双栏但减少内边距
- 手机（< 768px）：双栏折叠为单栏，表格保持水平可滚动，CTA 按钮全宽

---

## 技术约束

- 单文件 HTML + Tailwind CDN + 原生 JS
- 不依赖 npm/构建工具
- 注册链接为外部跳转（`target="_blank"`）

---

## 设计约束

- 事件性质：国际诗歌活动，在西班牙马德里皇家剧院举行
- 视觉气质关键词：文化底蕴、仪式感、温暖庄重、诗意、高雅
- 禁止使用：霓虹色、冰冷科技风格、过于现代极简的无衬线体作为主字体
- 建议使用衬线字体（serif）营造传统文学感
