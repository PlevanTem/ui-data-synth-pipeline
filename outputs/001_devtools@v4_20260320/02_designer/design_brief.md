# Design Brief — PulseForge

## 核心视觉方向
- 方向：`Neuro-Flow Neumorphism`
- 基调：暗色专业、软深度层次、数据驱动动态反馈
- 目标：让用户在高密度信息中维持“冷静掌控”并快速决策

## 布局策略
- 顶部全局控制栏承载 workspace、时间窗、模式切换、语音入口。
- 主体采用“拓扑探索 + 趋势分析 + 明细表格”三核并行结构。
- 右侧或抽屉承载节点详情与修复建议，避免主视图跳出。

## 交互重点
- 导航切换：Overview / Root Cause / Optimization 三视图切换。
- 筛选联动：时间、服务、严重度筛选同步影响图、表、洞察卡。
- 语音查询：listening -> processing -> applied 状态闭环，结果自动映射到筛选器。
- 节点下钻：点击拓扑节点或表格行，联动详情面板与图表高亮。

## 页面内部交互完整清单
- 导航：顶部导航与视图标签真实切换内容区。
- Filtering：搜索、筛选、排序真实作用于数据集。
- Forms：查询输入与语音确认具备验证和提交反馈。
- Component Communication：
  - 筛选器 -> 拓扑/图表/表格
  - 表格选中 -> 详情面板
  - 主题切换 -> 全局 token 与生成式层参数
- Overlay：详情抽屉、错误弹窗、toast 全流程可开关。
- 状态层：loading / empty / error / retry 必须覆盖关键模块。

## 动画与视觉母题边界
- 必须保留：
  - 新拟态软深度（卡片内凹/外凸、柔和阴影）
  - 数据变化过渡（数字滚动、折线缓动、节点脉冲）
  - 生成式层与数据状态联动
- 禁止：
  - 无信息价值的持续大幅动效
  - 过亮发光导致文本对比下降
  - 仅保留视觉皮肤而移除交互闭环

## Generative 视觉层实现指南
- 推荐算法：
  - 主层：Flow Field（噪声向量场）
  - 次层：Particle Pulse（按严重度映射亮度/密度）
  - 信息层：SVG path morph / tooltip spring
- 参数范围建议：
  - 粒子密度：40-140（依据设备性能动态调整）
  - 噪声尺度：0.003-0.012
  - 运动速率：0.15-0.55
  - 主层透明度：0.12-0.28，保证内容可读
- 美学目标：背景活性可感知但不抢夺主信息焦点。

## 组件气质
- 关键词：precise, calm, technical, responsive, premium
- 组件反馈需“清楚且克制”：明确状态变化，不做夸张娱乐化动作。

## Frontend 禁止事项
- 禁止静态假交互（按钮/筛选器无实际行为）。
- 禁止将生成式模块直接耦合在页面组件中（需独立模块）。
- 禁止忽略 `prefers-reduced-motion`。
- 禁止使用默认模板风格而不做定制化 token 映射。
