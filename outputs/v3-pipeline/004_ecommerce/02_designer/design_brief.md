# Design Brief: Nebula Commerce

To: Frontend Agent
From: Designer Agent

## 核心视觉方向
**Liquid Glass (流体玻璃)**。这不只是一个简单的 CSS blur 效果，而是一个动态的、有物理反馈的玻璃生态系统。
- **背景**：实时的 WebGL 流体渐变（Aurora），模拟极光或液态金属流动。
- **前景**：高透磨砂玻璃卡片，带有动态光边（Border Glow）。
- **数据层**：Canvas 绘制的知识图谱，节点带有呼吸感。

## 布局策略
- **Mobile-First Bento Grid**：首页采用非对称的 Bento Grid 布局，突出“探索”感。
- **Floating UI**：导航栏、操作栏全部悬浮，不贴底不贴顶，强化“层级感”。
- **Infinite Scroll**：垂直方向无限滚动，水平方向在特定区块（如推荐）可滑动。

## 交互重点 (Interaction Integrity)
页面内部交互必须完整实现，**拒绝只有外观的空壳**：
1. **知识图谱**：点击节点 -> 节点高亮并吸附中心 -> 底部弹出玻璃面板显示详情。
2. **筛选器**：点击 Filter -> 玻璃面板实时模糊背景 -> 选择后列表即时重排（Flip 动画）。
3. **表单**：输入框聚焦时，玻璃背景亮度提升（Luminance Boost），光标跟随粒子效果。
4. **3D 查看器**：单指旋转，双指缩放，惯性阻尼必须调教顺滑。
5. **购物车**：添加商品时，商品缩略图抛物线飞入购物车图标，图标产生弹性形变。

## Generative 视觉层指南
- **背景 Shader**：使用基于 noise 的颜色混合算法，速度缓慢，营造梦幻感。
- **图谱连线**：使用 D3.js 力导向图，但连线使用动态粒子流，而非实线。
- **Loading**：程序化生成的几何图形变换，不使用 GIF。

## 禁止事项
- **禁止**使用纯色白背景（#FFFFFF），必须叠加噪声纹理或渐变。
- **禁止**使用系统默认阴影，必须使用多层彩色弥散阴影（Glow）。
- **禁止**点击无反馈，所有可点击区域必须有 Scale 或 Brightness 响应。
