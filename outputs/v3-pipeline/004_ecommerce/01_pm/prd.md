# Product Requirements Document (PRD): Nebula Commerce

## 1. 项目概述
Nebula Commerce 旨在解决传统跨境电商应用在移动端体验割裂、信息展示效率低、视觉同质化严重的问题。通过引入 WebGL 渲染引擎和可视化知识图谱，构建一个兼具高性能与高审美（Apple-style 磨砂玻璃质感）的下一代移动端电商体验。

## 2. 目标用户与场景
- **目标用户**：25-35 岁，对生活品质有要求，习惯使用 iOS 生态应用，对交互流畅度和视觉美感敏感的跨境购物者。
- **核心场景**：
  - 在通勤途中单手操作，快速浏览高品质商品。
  - 通过自然语言（如“适合送给设计师的极简风格桌面摆件”）进行模糊搜索，并在知识图谱中发现关联商品。
  - 在购买前全方位查看商品细节（3D/高清细节）。

## 3. 核心问题定义
- **移动端体验差**：传统电商 App 堆砌信息，忽视单手操作和视觉层级，导致认知负荷过重。
- **搜索效率低**：关键词匹配往往无法理解用户的真实意图，缺乏关联发现能力。
- **视觉平庸**：千篇一律的白色卡片式设计，缺乏品牌辨识度和高级感。

## 4. 功能需求
### 4.1 可视化知识图谱与语义搜索 (P0)
- **输入**：支持自然语言输入查询。
- **展示**：不直接展示列表，而是先展示一个基于 Canvas/D3 的交互式节点图，显示商品与其属性、场景、关联品的连接。
- **交互**：用户可以点击节点进行筛选、缩放查看分支，长按预览商品卡片。

### 4.2 WebGL 大数据量渲染引擎 (P0)
- **商品展示**：详情页支持 WebGL 驱动的 3D 模型查看或高性能图片流缩放。
- **列表性能**：在浏览大量商品图时，使用自定义 Shader 优化加载与转场，确保 60fps 流畅度。

### 4.3 无障碍 (a11y) 适配表单系统 (P0)
- **语义化**：所有表单控件必须有清晰的 label 和 aria 属性。
- **键盘支持**：移动端虚拟键盘类型自动适配（数字、邮箱等）。
- **错误反馈**：实时校验，错误信息不仅有颜色变化，必须有图标和文字说明，支持 Screen Reader 读取。
- **Focus 管理**：模态框打开时焦点自动捕获，关闭后归位。

### 4.4 Apple-style 磨砂玻璃质感 UI (P0)
- **视觉风格**：大面积使用 Backdrop Filter (Blur)，配合半透明白色/深色背景，营造层次感。
- **一致性**：图标、圆角、字体（San Francisco/Inter）需严格遵循 iOS Design Guidelines 变体。

## 5. 非功能需求
- **性能**：移动端首屏 LCP < 1.5s，交互 FID < 100ms。
- **兼容性**：iOS 16+, Android 10+ (针对不支持 backdrop-filter 的设备需有降级方案)。
- **可访问性**：WCAG 2.1 AA 标准。

## 6. 交互结构
- **导航**：底部悬浮导航条 (Floating Tab Bar)，配合全屏手势返回。
- **层级**：通过磨砂玻璃的模糊度和亮度区分层级，而非仅靠阴影。
- **转场**：页面间无缝过渡 (Shared Element Transition)，避免硬切。

## 7. 验收标准
1. 知识图谱搜索能正确响应点击并筛选商品。
2. 详情页 3D/高清图在 iPhone 12 及以上机型流畅运行。
3. 所有表单均可通过 Screen Reader 正常操作。
4. 视觉上无实色背景遮挡，磨砂玻璃效果通透且不卡顿。
