# 鸿蒙智联全屋智能中控应用 PRD

## 一句话定义
这个产品帮助智能家庭用户在多端设备（手机/平板/智慧屏）上解决鸿蒙智联全品类IoT设备操控繁琐、无统一管理入口的问题，让他们能通过极简直观的卡片化界面和一键场景联动，实现全屋智能设备的统一且高效的管理。

## 推理记录

### 用户与场景分析
- **谁在用？** 现代家庭中的各类成员，从对技术敏感的年轻人到需要极简操作的长辈。他们具有一定的审美要求，追求生活品质和高效率。
- **什么场景下用？** 
  - 日常居家期间的高频设备调控（如开关灯、调温）。
  - 生活状态切换时（离家、回家、睡眠、观影）的批量设备联动。
  - 需要统览家庭状况（设备在线离线、室内温湿度、能耗等）。
- **痛点：** 现有的智能设备往往入口分散，操作层级深；缺乏直观的状态反馈；场景控制不够自动化。
- **目标：** 统一入口、一键触达、状态可视化、多端无缝体验。

### 核心问题定义
核心问题在于“设备碎片的整合与交互效率的提升”，产品不仅要实现基础的控制功能，更要通过空间隐喻、卡片模块化、多端一致的设计语言重构全屋智能的交互心智。

### 实体与功能推导
**实体清单 (Entities)：**
- `Device` (设备)：包含状态（开/关/在线/离线）、类型（灯光/安防/环境/影音）、参数值（亮度、温度等）。
- `Scene` (场景)：包含场景名称（回家/离家等）、触发动作集合、图标/状态。
- `Environment` (环境)：室内温湿度、空气质量、整体能耗数据。

**功能清单 (Features)：**
- **显性功能：**
  - 设备状态实时监控（设备列表及卡片展示）
  - 一键场景联动控制
  - 语音助手入口（对接小艺模拟或预留视觉反馈）
  - 模块化设备卡片操作（开关及参数调节）
  - 基础能耗统计与图表查看
- **隐性功能：**
  - 实时数据状态同步反馈（防止操作后无响应）
  - 多端适配的响应式布局（手机/平板/智慧屏的断点适配）
  - 设备离线/加载中的异常状态反馈
  - 交互过渡动画（卡片点击反馈、场景切换动画）

**数据交互清单：**
- 实时读取设备和环境状态。
- 异步下发设备控制与场景执行指令。

**功能架构：**
- **Dashboard（核心视图）**：汇聚环境总览、高频场景、常用设备卡片。
- **Devices（设备管理）**：按房间或类型维度的设备筛选与精细控制。
- **Analytics（能耗统计）**：数据可视化面板。

### 非功能需求推导
- **性能感知：** 状态同步需要极低的视觉延迟（可通过乐观更新优化体验）。
- **视觉信任感：** 需要达到 `premium`（高端）级别，契合2026智能家居中控极简直观、色彩柔和、拟真/玻璃态等前沿风格。
- **交互密度：** 高（Rich），频繁的轻量点击与滑动调节。
- **情绪目标：** 宁静、掌控感、现代科技感。

### 取舍说明
- **S类降级：** 真实的语音控制（对接小艺）在前端原型阶段降级为仅展示“视觉交互与录音态动画反馈”。能耗统计的深层细分数据在受限时可降级为“今日概览”。复杂的模块化卡片“自由拖拽排版”降级为“响应式流式布局”。
- **X类排除：** 家庭成员账户与权限分离。本次重心为“统一管理入口的交互体验”，权限分离功能会导致演示焦点偏移。

## 执行契约摘要
- **M (Must Deliver):** 环境概览与欢迎语、一键场景联动模块、设备模块化控制卡片、设备状态的实时交互反馈（如开关动效、乐观更新）、跨端响应式布局（Mobile/Tablet）。
- **S (Should Deliver):** 语音交互状态的微动效（Voice Assistant UI）、能耗图表的可视化呈现。
- **X (Excluded):** 多账户权限管理。

## 设计约束
- 风格需遵循2026智能家居中控新趋势（如极简卡片、色彩柔和、玻璃态或空间层级感）。
- 强调多端（Mobile为主，兼顾Tablet横屏）界面的自适应美感。

## 边界情况
- 当设备全部离线时界面的空状态或错误提示。
- 在大屏（Tablet/智慧屏）下，卡片排列的合理性不能简单拉伸，而应充分利用空间增加列数或并排显示图表。
