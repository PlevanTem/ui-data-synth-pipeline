# 鸿蒙智联中控 - 设计执行简报 (Design Brief)

## 1. 核心视觉方向
**Dark Minimalist Fluid (深色极简流体态)**。整体气质追求：高端、宁静、秩序感。界面应像是悬浮在一块微光流动的深色磨砂玻璃上。
- **主色调**：深邃中性灰/黑 (`#09090B`, `#18181B`)，而非刺眼的纯黑或科技蓝。
- **材质感**：使用极其克制的 Glassmorphism（玻璃拟态），仅用于卡片层，提供空间隔离；带有极其细微的白色/高光上边框，以强调厚度和物理质感。

## 2. 布局策略
- **Mobile First**：底部固定导航 (Bottom Tab)，主体采用单列/双列瀑布流栅格。顶栏为环境概览，中段为快捷场景，下段为平铺的设备卡片。
- **Tablet / Desktop**：左侧边栏导航。主内容区左右分栏（左侧环境与场景流，右侧密集设备卡片网格）。
- **空间利用**：模块之间保持充裕的间距 (gap: `16px` / `24px`)，卡片内信息排版要求呼吸感。

## 3. 交互重点与内部联动
- **设备开关联动**：卡片本身既是信息展示，也是操作载体。点击开关按钮时，整个卡片的亮度/背景色应有明显的明暗交替过渡（模拟灯光的点亮/熄灭）。
- **场景触发联动**：点击“观影模式”时，场景卡片进入 `loading` / `active` 发光态；同时，关联的“电视卡片”、“灯光卡片”应自动、依次在界面上呈现状态反转动画。
- **语音唤醒联动**：点击顶部的“小艺语音”入口，弹出一个底部抽屉或悬浮模态框，伴随流体波形的麦克风收音动画。

## 4. Generative 视觉层的实现指南
- **背景层 (Environment Flow)**：推荐使用 Canvas/WebGL 实现一个极慢流动的彩色噪声背景。当处于“日常模式”时，以深灰+微弱蓝绿渐变为主；当切换为“睡眠模式”时，缓缓过渡为暗紫色。
- **性能要求**：背景层不得干扰设备卡片的滑动和点击响应。如果在低端设备上掉帧，必须无缝降级为 CSS Gradient。

## 5. 组件气质
- **圆角 (Radius)**：大圆角（卡片 `16px`-`24px`，按钮 `9999px` 胶囊型或 `12px`），传递包容与安全感。
- **阴影 (Shadow)**：摈弃重阴影，转用极微弱的外发光（Glow）或带有颜色的弥散阴影来表达选中状态。
- **排版 (Typography)**：清晰的无衬线字体（如 `Inter`, `SF Pro`）。数字（如温湿度）采用等宽特征的字体，增加工业/仪表的精致感。

## 6. 禁止事项
- 禁止使用刺眼的霓虹渐变色铺满整个卡片。
- 禁止组件出现瞬间跳变（无过渡动画的生硬反馈）。
- 禁止堆砌无意义的 3D 悬浮球或装饰性几何体，所有视觉表现都必须服务于“状态反馈”。
