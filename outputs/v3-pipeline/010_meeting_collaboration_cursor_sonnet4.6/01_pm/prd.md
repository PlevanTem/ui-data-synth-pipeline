# PRD: 鸿蒙智会 AI 会议 (Web App 原型)

## 项目概述
本项目旨在设计与实现一款符合 2026 办公协作新趋势的 AI 会议应用原型（基于前端技术栈模拟原生级体验）。针对“办公会议入会繁琐、纪要整理低效、多设备协作不便”的问题，界面要求清爽、极简商务风、低饱和配色。重点突出“一键入会”、“实时转写翻译”、“多设备协同”及“会后纪要智能生成”。

## 目标用户与场景
- **用户群**：追求极简与效率的商务办公人士、跨国团队协作人员。
- **核心场景**：
  - 差旅途中的急需参会：移动设备一键入会，低门槛。
  - 会议进行中：跨语言交流需要实时翻译字幕，并需在多设备（平板/智慧屏）上进行内容批注。
  - 会议结束：主管或执行者需快速浏览自动生成的纪要，分发待办任务。

## 核心问题定义
- 入会流程长，找不到会议链接。
- 跨设备会议体验割裂，手机、平板和电脑不能很好地联动。
- 手工记录效率低，且容易遗漏重点，会后跟进困难。

## 功能需求 (模拟实现)
1. **多端极速入会**：卡片化日程展示，醒目的“一键入会”交互体验（微动效过渡）。
2. **沉浸式通话与协作**：
   - 视频/语音主界面。
   - 动态呼出的“实时语音/多语言字幕转写”面板。
   - 侧边栏/浮层的“画笔批注”工具激活态模拟。
3. **AI智能纪要与待办**：
   - 模拟会议结束后自动生成：核心要点区块、时间轴记录、结构化待办任务（Task list）。
   - 待办支持状态勾选。

## 非功能需求
- **视觉风格**：贴合 2026 办公新趋势，极简商务风，低饱和配色（如高级的灰蓝、米白、冷灰），具备空间呼吸感。
- **性能与动效**：模块间状态流转需平滑流畅（使用 CSS/JS 动画），无多余冗余功能。
- **响应式要求**：必须适配移动端、平板跨屏以及宽屏桌面，体现出一致的设计语言但因地制宜的布局策略。

## 页面与交互结构
采用 Web App Shell 单页架构进行呈现。
关键视图路径为主导航栏切换或状态流转：
- **视图A (Dashboard)**：我的日程与近期会议清单。
- **视图B (Meeting Space)**：会中模式，包含视频流模拟位、实时翻译面板。
- **视图C (AI Summary)**：会后智能总结、待办列表与分发状态。

## 设计约束
- 避免同质化的复杂三栏后台设计，要求具有轻量版移动优先、鸿蒙原生系统的质感（轻盈、微动效、卡片高斯模糊层次、模块化圆角）。
- 任何组件切换必需伴随逻辑或视觉上合理的转场。

## 技术约束
- 采用组件化框架（如 Vue + TS 或 React + TS）落地。本 PRD 指导最终的前端结构划分。
- 应用层逻辑无需真实通讯，必须使用 mock 数据实现真实的导航、组件挂载、路由联动与状态变更。

## 验收标准
- 用户能在应用内平滑体验"查看日程" -> "进入会议" -> "使用翻译/批注工具" -> "查阅智能纪要/待办" 的完整流程。
- 设计语言高端克制，交互如流水般自然。
- 页面必须真实具有三种响应式断点的合理布局表现。
