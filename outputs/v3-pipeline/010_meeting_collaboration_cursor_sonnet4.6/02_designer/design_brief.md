# Design Brief: 给 Frontend Agent 的执行指南

## 核心视觉方向
Hyper-Minimal Business (2026 Trend) + Harmony Fluidity
极简商务风、带有一丝柔性流体感。使用大圆角、模糊材质层以及极微弱的背景颗粒噪点营造原生系统体验感。

## 布局策略
- App Shell 结构，不采用传统的页面跳转。
- **Mobile First** 思想：以卡片流为基础框架；在宽屏桌面端则为扩展版（例如：左侧卡片列表，右侧大面积详情视窗或视频主视觉）。

## 交互重点与内部交互清单
必须实现以下完整前端交互：
1. **多端入会流**：从 Dashboard 点击入会按钮 -> 触发全屏展开的转场动画 -> 显示会中界面（主功能区模拟开启视像）。
2. **会中工具**：点击底栏工具（翻译、画笔） -> 在侧边平滑滑出抽屉或在主区浮出控制面板。
3. **结束会议**：点击挂断 -> 页面路由至 Smart Summary 纪要页 -> 展示纪要结果和可交互的待办 Task List。

## 动画 / 视觉使用边界
- 禁止使用生硬的跳转（无过渡）。所有组件加载、切换均需要配合渐入或展开动画（Duration 350ms, cubic-bezier 曲线）。
- **Generative 附加层**：为全局 `body` 或顶层容器添加一层极淡的噪点滤镜与两团极其缓慢移动的柔光 CSS radial-gradient，营造空间感。不要使用 WebGL 这类重型库。

## 组件气质
- 克制、内敛，用极细的 border(`1px solid rgba(0,0,0,0.05)`) 来勾勒边界。
- 不要有太多刺眼的阴影，大量使用 `backdrop-filter: blur(20px)` 区分层级。
