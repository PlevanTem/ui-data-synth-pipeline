# PRD: 鸿蒙原生 AI 会议协作应用

> 面向 Designer Agent 和 Frontend Agent 的产品规格文档。  
> 本 PRD 基于原始需求提炼，非原文转录。

---

## 1. 项目概述

本项目为一款运行在鸿蒙生态（HarmonyOS）的 AI 会议协作 Web 演示原型，模拟产品的核心界面和交互流程。前端以 Web 应用形式交付，但视觉和交互逻辑贴合鸿蒙多设备、分布式协作的设计语言。

核心定位：**以"会议全流程 AI 托管"为差异化**，覆盖从入会前准备→会中实时协作→会后纪要输出的完整闭环，减少手工整理负担，提升跨设备协同效率。

---

## 2. 目标用户与场景

### 目标用户
- **主用户**：企业/组织中参与中高频会议的知识工作者（产品、运营、管理、销售等岗位）
- **次用户**：会议组织者（秘书、项目 PM、行政）

### 核心场景
1. 多端一键快速入会（手机/平板/智慧屏）
2. 会议中实时语音转写 + AI 摘要浮层
3. 会议结束后 AI 自动生成结构化纪要和待办任务
4. 跨设备协作批注（平板 → 智慧屏投屏）
5. 任务同步与跟踪

---

## 3. 核心问题定义

| 痛点 | 当前状态 | 目标状态 |
|------|----------|----------|
| 入会流程繁琐 | 手动查找链接/密码，多步操作 | 一键识别/跳转，0 繁琐步骤 |
| 纪要整理低效 | 手动记录，事后整理耗时 1-2h | AI 实时转写+会后自动生成，人工确认即可 |
| 多设备协作不便 | 单端操作，内容不互通 | 鸿蒙分布式：手机→平板→智慧屏无缝流转 |
| 任务分配易遗漏 | 纪要中的任务项易被忽略 | AI 自动提取任务→推送至待办 |

---

## 4. 功能需求

### Must Have（P0）
- **多设备快速入会**：展示手机/平板/智慧屏三端入会界面，支持一键入会状态演示
- **实时语音转写面板**：会议中浮层显示实时字幕，带发言人标注
- **AI 摘要条**：会议进行中实时生成关键要点，侧边栏展示
- **会后纪要页**：结构化纪要（议题/决策/行动项），支持导出模拟
- **任务待办面板**：从纪要提取的任务列表，支持指派/状态更新
- **多语言切换**：纪要支持中/英文版本切换（模拟）

### Should Have（P1）
- **会议列表/历史**：历史会议检索，快速回顾纪要
- **投屏预览**：模拟智慧屏投屏预览状态
- **主题/夜间模式切换**：适配办公场景的亮/暗主题
- **移动端响应式**：手机端可用的紧凑布局

### Nice to Have（P2）
- **批注工具**：文档/白板上的协作标注功能演示
- **参会者状态标注**：静音/发言/断开等状态图标
- **AI 智能建议**：基于议题的下一步行动建议气泡

### Out of Scope
- 真实 WebRTC 音视频通话
- 真实语音识别 API 集成
- 后端存储和用户认证
- 鸿蒙原生 ArkTS 代码实现（本次为 Web 演示原型）

---

## 5. 非功能需求

- **性能**：首屏加载 < 3s，动画 60fps
- **响应式**：桌面（1440px）/ 平板（768px）/ 手机（375px）均可用
- **可访问性**：对比度 WCAG AA 级，焦点可见
- **视觉风格**：极简商务风，低饱和度配色，贴合 2026 办公协作美学
- **多设备感知**：界面要体现"跨设备无缝流转"的空间感

---

## 6. 页面与交互结构

### 应用结构：单页 Web App（SPA）

```
App Shell
├── 顶部导航栏（设备切换模拟 + 主题切换 + 用户头像）
├── 侧边导航（会议列表 / 当前会议 / 历史纪要 / 任务）
└── 主内容区（视图切换）
    ├── 视图 A：首页 Dashboard（即将到来的会议 + 快速入会）
    ├── 视图 B：会议进行中（转写面板 + 摘要 + 参会者）
    ├── 视图 C：会议纪要（结构化纪要 + 多语言切换 + 导出）
    └── 视图 D：任务待办（任务列表 + 状态管理）
```

### 核心用户流
1. **快速入会流**：Dashboard → 点击"加入会议" → 进入会议视图（转写面板激活）
2. **纪要生成流**：会议视图 → 点击"结束会议" → 纪要自动生成动画 → 跳转纪要视图
3. **任务提取流**：纪要视图 → AI 高亮行动项 → 一键同步到任务面板
4. **多端流转**：顶部设备切换 → 布局响应式变化 + 投屏模拟动画

## 7. 设计约束

- **配色**：低饱和度商务色系（非紫蓝渐变），鸿蒙 ArkUI 风格参考
- **字体**：中英文双语良好支持，信息密度高但不压迫
- **图标**：线性图标系统，贴合鸿蒙设计语言
- **动效**：克制的功能性动效（过渡、出现/消失），禁止无意义特效
- **交互密度**：中高密度，信息驱动型界面

---

## 8. 技术约束

- TypeScript + 组件化框架（React/Vue 均可）
- 无真实 API 依赖，所有数据为 mock
- 纯前端运行，`npm run dev` 可启动
- 不使用外部后端服务

---

## 9. 边界情况

- 会议列表为空时需有空态引导
- 转写内容为模拟流式输出（setInterval 模拟）
- 纪要生成使用动效模拟 AI 处理过程
- 设备切换为视觉模拟，不是真实鸿蒙分布式调用

---

## 10. 验收标准

- [ ] 四个视图之间可完整导航切换
- [ ] 会议流程可端到端演示（入会 → 转写 → 结束 → 纪要 → 任务）
- [ ] 实时转写面板有流式模拟动效
- [ ] 任务面板支持状态切换
- [ ] 多语言切换纪要内容变化
- [ ] 响应式在三种断点下可用
- [ ] 亮/暗主题切换有效
- [ ] 无明显 TypeScript 类型错误，`npm run dev` 可启动
