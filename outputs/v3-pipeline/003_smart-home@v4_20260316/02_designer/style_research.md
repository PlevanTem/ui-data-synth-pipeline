# Style Research: 鸿蒙智联全屋智能中控

## 调研方向与结论

### 1. 2026 智能家居中控 UI 主流趋势

**核心设计哲学**（来自实际调研）：
- 2026 智能家居仪表盘核心原则：**信息在用户提问之前就已呈现**，一屏掌握全局，减少导航层级
- 最小化杂乱感是主流，不追求视觉炫技，而是追求"信息架构即设计"
- Grid Card 成为标准布局单元，替代嵌套 stack 复杂结构
- Button-card-first 设计系统：统一模板、限制嵌套深度（最多2层）

**本案差异化切入点**：
主流 Home Assistant 社区方案偏向工具感（功能导向），缺少情感温度。本案要在"极简工具感"和"居家温暖感"之间找到独特平衡——借鉴苹果 Home App 的优雅，融合华为 HarmonyOS 的圆润，加入 Ambient Glow 的氛围层。

---

### 2. Dark Mode + Ambient Glow 美学（2026主流）

**Dark Glassmorphism** 已确认为 2026 UI 定义美学：
- 多层透明度叠加（而非纯色背景）
- backdrop-filter: blur(12px-20px) 实现磨砂玻璃感
- 设备状态以发光指示器体现（绿色=安全/在线，暖橙=加热，冷蓝=冷却）
- Liquid Glass 进化版：关注可读性和层次感，不止追求效果

**本案调研参考**（Dribbble案例）：
- Smart Home Control by 智能家居设计师：暖色主调(#130E09, #E2EAF1, #4A3423)，自然有机感
- Lifesmart App：AI 通知卡片 + 设备卡片按钮切换，软色调（青绿+灰褐+哑光）
- Neumorphic Smart Home：深色背景下的凸起感卡片，适合设备开关的物理质感模拟

---

### 3. 能耗数据可视化趋势

**2026 能耗 Dashboard 最佳实践**：
- 多时间维度（今日/7日/30日）+ 趋势指示器
- 顶级耗能设备排行榜
- 圆形进度条表达目标完成度
- 实时折线/面积图（Chart.js / D3.js 渲染）
- 设备图标动画响应能耗状态

---

### 4. 探索的风格方向与选择

**方向A：纯极简功能流（拒绝）**
- 白底卡片，无氛围感
- 优点：信息清晰；缺点：Premium感缺失，与华为生态用户审美期待不符
- **排除原因**：premium用户期待视觉层级与质感

**方向B：深色 Glassmorphism + 暖光发光（选择）**
- 深炭灰底（#0F1117）+ 磨砂玻璃卡片（15-20%透明）
- 设备激活时暖橙/暖黄发光（模拟真实灯光氛围）
- 夜间暖调、白天冷调自适应
- **选择原因**：与智能家居"氛围控制"产品语义高度吻合，Premium感强，卡片层次分明

**方向C：HarmonyOS 浅色扁平（拒绝）**
- 浅灰白底，EMUI风格圆角卡片
- 优点：熟悉感强；缺点：视觉平庸，缺乏差异化
- **排除原因**：输出目标是"值得作为设计参考"的水准，不能过于保守

---

### 5. 本案最终风格定位

**"Ambient Dark Control" — 暗色环境智能控制风格**

- 深沉的炭灰/近黑背景，赋予高级感
- 设备卡片以磨砂玻璃质感悬浮，激活时发出对应设备类型的光晕
- 场景切换产生"涟漪扩散"的光感动效
- 能耗图表以冷暖色编码区分耗能等级
- 圆润大圆角（16-24px），避免锐利棱角，保持居家温馨感
- 排版使用大字重数字 + 细字重标签的强弱对比
- 这套风格既避免了"科技冷漠感"，又提升了视觉层次，是当前智能家居中控市场的空白地带

---

### 6. 差异化记录

本案与过往可能产出的区别：
- **非**纯白卡片+紫蓝渐变的标准 SaaS 风格
- **非**居中大标题+三栏卡片的营销页结构
- **非**单纯的功能工具界面，而是有**环境感**（ambient）的生活产品界面
- 设备卡片的发光状态是核心差异化视觉语言，不是点缀
