# PsychePath CME Navigator PRD

## 核心问题定义
这个产品帮助高级临床心理学家在规划年度CME（继续医学教育）时，解决通用医疗资源与人格特质深度分析脱节的问题，让他们能通过个性化的技能雷达图和3D神经交互，直观、高效地定制自己的50小时专属进阶学分计划。

## 用户与场景分析
- **用户类型**：Dr. Aris Thorne，专注于人格特质分析（Personality Trait Analysis）的高级临床心理学家。具备深厚的专业背景，需要完成年度50小时的CME学分要求。
- **使用场景**：在电脑前规划新一财年的专业学习路径。用户登录专属 Dashboard，需要迅速发现自己在新领域（如大五人格临床应用、暗黑四分体等）与认证标准之间的差距，并针对性挑选高阶课程。
- **痛点**：现存继续医学教育资源泛滥且基础，难以筛选出将前沿人格理论与临床实践（尤其对应神经科学区域）紧密结合的高级课程。
- **目标结果**：获得一份结构化且个性化的“特质-知识缺口”（Trait-Knowledge Gap）分析，并在沉浸式互动中完成选课，通过直观的计算器轻松拼凑满50个CME学时。

## 设计意图
- **情绪目标**：打开瞬间感受到极高的专业权威度与前沿科技感；使用过程中（通过3D交互和拖拽规划）感受到探索的乐趣、个性化定制的掌控感，消除凑学分的枯燥焦虑。
- **信息密度**：high（包含复杂维度对比数据、3D模型标注、密集课程信息池）。
- **交互深度**：immersive（3D模型神经区点击联动、图表动态渲染、拖拽式规划计算）。
- **视觉信任感**：premium / professional（具备医疗领域的严谨冷静，同时融合神经科学的前沿科技氛围，如深邃冷色调结合发光高亮）。

## 功能契约

### Must Deliver（M）
| ID | 功能 | 验收条件 | 失败条件 | 表现力目标 |
|----|------|---------|---------|-----------|
| M01 | 技能缺口雷达图 (Skill-Gap Radar Chart) | 能正确渲染至少5个专业维度的多边形图表，同时显示“当前专长”与“认证要求”两个层叠多边形并能直观对比差距。 | 图表重叠模糊不可读，或无法响应静态初始化数据渲染，缺少维度的明确文本标签。 | 多边形加载时具有由内向外展开的丝滑生长动画，悬浮（Hover）时有清晰且具有现代感的数据 Tooltip 和坐标轴高亮。 |
| M02 | 3D 神经人格资源探索器 (Interactive 3D Brain Model) | 提供一个3D交互大脑或神经节点模型，点击不同脑区/节点（映射不同人格特质）时，旁侧课程列表联动过滤出对应主题的CME课程。 | 3D模型无法渲染、交互帧率极低卡顿，或点击热区无效、无法触发对应课程列表内容的更新。 | 极具科技感的半透明或线框材质脑模型，支持平滑拖拽旋转，点击脑区时具有发光激活动效及平滑聚焦过渡，联动面板呈现优雅的进入动画。 |
| M03 | 拖拽式年度学分追踪器 (Drag-and-Drop Credit Tracker) | 允许用户将课程池中的卡片拖入右侧（或底部）的年度学习计划区。拖入后，界面上的“总学时”数字实时累加，并更新“距离50小时目标”的进度条。 | 无法拖拽，放置目标区域不响应，学分数字不累加，或者移除时无法正确扣减学分，逻辑混乱。 | 拖拽时卡片悬浮（Elevation）并带阴影，放置区显示吸附提示（Dropzone highlight）；总学分数值变化时具有数字滚动上升动画（Count-up animation）。 |
| M04 | 选课进度条与目标反馈 | 当选课累积超过或等于50小时目标时，需有明显的达成状态反馈。 | 达到50小时后无任何状态变化，或进度条溢出破版。 | 进度条满时有庆祝性视觉动效（如进度条变色发光），CTA 按钮从不可用状态转换为引导提交的呼吸态。 |

|----|------|---------|---------|

## 内容意图地图（IA）

### 专家资质与目标概览 (Header / Profile Snippet)
- **意图**：确认用户身份（Dr. Aris Thorne），明确今年的核心任务（完成50小时CME）。
- **优先级**：P1
- **必须包含**：用户姓名、头衔（Clinical Psychologist）、执业领域标签、当前财年目标进度简要提示。
- **创作自由度**：content-fixed-layout-free
- **关联契约**：无

### 技能缺口分析区 (Skill-Gap Analysis)
- **意图**：通过数据可视化直观发现自己在大五人格、暗黑四分体等高阶维度的临床应用短板，明确接下来该学什么。
- **优先级**：P0
- **必须包含**：雷达图组件，当前评分与认证标准的分数对比，各评估维度的专业名称标签。
- **创作自由度**：fully-open
- **关联契约**：M01

### 神经人格课程探索区 (Neuro-Trait Resource Discovery)
- **意图**：通过前沿、沉浸的 3D 脑区交互激发探索欲，打破枯燥的列表筛选，依据脑区关联精准定位高阶课程。
- **优先级**：P0
- **必须包含**：3D 交互大脑/节点模型、当前选中区域的描述或标题、关联的课程列表（需体现：课程名、CME学分数、相关人格特质标签）。
- **创作自由度**：fully-open
- **关联契约**：M02

### 年度学分追踪与规划器 (Annual Learning Plan Tracker)
- **意图**：提供类似购物车的收集箱，模拟并追踪新一年的课程学习拼图，直至凑满50个学时目标。
- **优先级**：P0
- **必须包含**：已加入计划的课程列表区、当前累计总学时数值、距50小时目标的进度指示器（如环形或横向进度条）、生成/保存年度计划的操作按钮。
- **创作自由度**：content-fixed-layout-free
- **关联契约**：M03, M04

## 响应式优先级
**desktop-first**（桌面端优先）。由于该产品核心体验深度依赖于密集的医疗数据可视化（多维雷达图）、重度交互（3D脑模型）以及复杂的拖拽式规划器（Drag-and-Drop），其最大的产品价值必须在大屏下才能完美展现。移动端主要满足查看已有进度和轻量浏览课程的诉求，必须做适当的视觉与交互降级。

## 技术约束
- **基础栈**：单文件 HTML，Tailwind CSS（CDN 引入）负责样式，原生 JavaScript 处理逻辑。
- **3D 交互**：需引入 Three.js CDN 实现脑模型或神经节点的渲染与交互。
- **图表**：需引入 Chart.js 或 ECharts 的 CDN 渲染雷达图。
- **拖拽**：可利用 HTML5 原生 Drag and Drop API 实现，或引入轻量级的 SortableJS 等拖拽库 CDN。

## 设计约束
- **视觉风格**：深色模式优先（Dark Mode），契合神经科学的深邃科技感以及医疗专业性；关键数据及高亮脑区可使用荧光色（如发光蓝、青色或紫色）作为点缀，营造前沿科研氛围。
- **排版排布**：Dashboard 需要在第一屏呈现所有核心模块，减少滚动；图表、3D模型与拖拽区在屏幕空间上应有极佳的平衡感和关联引导性。
