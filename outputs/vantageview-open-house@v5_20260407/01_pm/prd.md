# VantageView Themed Virtual Open House Portal — PRD

## 核心问题定义

这个产品帮助**奢侈地产经纪人（Sarah）**在**季节性营销活动节点**下解决「静态3D看房缺乏情感紧迫感、无法形成同步观看热场效应」的问题，让她能够**通过主题化时间表驱动潜在买家在特定日期聚合观看，实现情感共鸣式置业转化**。

---

## 用户与场景分析

| 维度 | 内容 |
|------|------|
| 主要用户 | Sarah — 奢侈物业管理人，主导营销日历，对视觉质感极度敏感 |
| 使用场景 | 在办公室或iPad上规划下一季开放日日程、预览不同时段的空间氛围、查看过往主题活动的转化数据 |
| 核心痛点 | 1. 传统3D巡游无时间感，买家随时进入无集中效应；2. 不同季节/时段氛围无法预判效果；3. 无法量化哪个主题最有吸引力 |
| 目标结果 | 一个操盘台：设定主题开放日→预览氛围→发布→复盘数据，全链路在一个界面完成 |
| 次要用户 | 潜在买家（仅在Open House活动日期体验沉浸场景，非本产品主要视角） |

---

## 设计意图

- **情绪目标**：打开后有「进入奢侈品牌旗舰店」的质感——克制、优雅、有温度；使用过程中保持专注与掌控感
- **信息密度**：medium（控制台逻辑但用大面积留白支撑高端感）
- **交互深度**：immersive（Atmosphere Slider必须有实时视觉响应；主题选择有空间感切换）
- **视觉信任感**：luxury（避免广告感、避免SaaS工具感，接近建筑事务所官网或高端钟表品牌数字报告的质感）

## 功能契约

### Must Deliver（M）

| ID | 功能 | 验收条件 | 失败条件 | 表现力目标 |
|----|------|---------|---------|-----------|
| M01 | 主题开放日日历排期 | 可选择日期；可从 Golden Hour / Midnight Modern / Festive / Sunset Soirée / Holiday Home 中分配主题；已排期日期有视觉标注 | 日期无法选择或主题无法保存 | 日历本身要有高级感，主题选中时有氛围色彩变化；卡片悬停有深度感 |
| M02 | Atmosphere Slider 时段预览 | 滑动条覆盖 6:00 AM–10:00 PM；属性场景光照/氛围色随时间连续变化；支持实时拖拽更新 | 滑动无视觉响应；只能跳档不能连续 | Canvas/WebGL实现光色渐变层；「黄金时段」有特效高亮；空间感强 |
| M03 | 参与热度分析面板 | 展示按日期/主题维度的用户兴趣数据；支持主题筛选器切换；图表随筛选实时变化 | 图表为静态图片；筛选无联动 | 数据可视化需有动效入场；图表与卡片联动 |
| M04 | 主题选择与预览切换 | 点击不同主题时，主视觉区呈现对应氛围（色调、光效、装饰元素）；切换有过渡动画 | 主题选择无视觉反馈 | 主题切换用沉浸式过渡；不同主题视觉差异明显 |
| M05 | 导航与多视图切换 | 顶部导航可切换「Schedule」「Preview」「Analytics」三个视图；切换有过渡动画 | 导航点击无响应 | 当前视图有明确指示；切换有平滑淡入淡出 |

### Should Deliver（S）

| ID | 功能 | 理想形态 | 降级底线 |
|----|------|---------|---------|
| S01 | 开放日事件卡片详情 | 点击日历中已排期事件弹出详情抽屉，包含主题、时间、预期参与人数 | 仅显示 tooltip |
| S02 | 主题颜色/装饰快速自定义 | 在选定主题基础上微调强调色 | 主题固定不可调 |
| S03 | 移动端响应式 | 完整适配手机端，Slider可触控操作 | 桌面端完整，移动端基础可读 |
| S04 | Toast 通知系统 | 排期保存成功/失败均有 toast 反馈 | 仅 console.log |

### Excluded（X）

| ID | 功能 | 排除原因 |
|----|------|---------|
| X01 | 实际3D引擎渲染真实房产 | 超出单文件HTML范围；氛围模拟已足够传达核心体验 |
| X02 | 用户账户系统/后端 | 纯前端原型，状态在内存中维持 |
| X03 | 买家端视图 | 本产品面向经纪人；买家端是独立产品 |

## 内容意图地图（IA）

### 品牌头部导航
- 意图：建立奢侈品牌调性；快速跳转三个主功能视图
- 优先级：P0
- 必须包含：Logo/产品名（VantageView）、三个视图入口（Schedule / Preview / Analytics）、当前视图指示
- 创作自由度：content-fixed-layout-free
- 关联契约：M05

### Atmosphere Slider（首屏沉浸工具）
- 意图：让 Sarah 在提交排期前感受不同时段的空间氛围，建立情感锚点
- 优先级：P0
- 必须包含：时间刻度（6AM–10PM）、属性场景可视化区域（光影响应）、当前时段标签、当前对应主题推荐提示
- 创作自由度：fully-open
- 关联契约：M02, M04

### 开放日排期日历
- 意图：Sarah 选择具体日期并绑定主题，完成开放日安排
- 优先级：P0
- 必须包含：月历视图、已排期日期高亮、主题分配控件（选择器）、保存操作
- 创作自由度：content-fixed-layout-free
- 关联契约：M01, S01, S04

### 主题选择面板
- 意图：Sarah 浏览所有可用主题、理解每种主题的视觉调性
- 优先级：P1
- 必须包含：主题名称（5种）、主题氛围关键词、视觉预览色块/图示、当前选中状态
- 创作自由度：fully-open
- 关联契约：M04, S02

### 参与热度分析面板
- 意图：Sarah 复盘哪些主题/日期最能吸引买家兴趣，优化下次排期策略
- 优先级：P1
- 必须包含：日期维度趋势图、主题维度对比图、总参与人次指标、主题筛选器
- 创作自由度：content-fixed-layout-free
- 关联契约：M03

---

## 响应式优先级

**Desktop-first**（Sarah 主要在桌面工作台使用），确保 1280px+ 完整体验；768px 断点适配 iPad；移动端保持基础可读（S03 级别）。

---

## 技术约束

- 单文件 HTML + Tailwind CDN + 原生 JS
- 浏览器直接打开，无需构建
- Canvas 或 Three.js 实现 Atmosphere Slider 的光效层
- 数据可视化使用 Chart.js 或 D3

---

## 设计约束

- 必须体现奢侈地产行业调性，而不是 SaaS 工具感
- 主题色随「当前活跃主题」联动变化（全局氛围随主题切换）
- 无大量文字说明，靠视觉和空间感传递品牌价值
