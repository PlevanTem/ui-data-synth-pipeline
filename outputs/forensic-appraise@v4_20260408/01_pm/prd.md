# Product Requirements Document (PRD)

## 1. 项目背景与目标
- **项目名称**: ForensicAppraise - Case Volume & Resource Analytics Dashboard
- **业务背景**: 法医鉴定中心（Technical Identification）面临不同法律类别鉴定对象（患者）大量涌入的挑战。首席鉴定师 Li 博士需要监控“患者”数量，以防止案件积压，并确保特定伤害类型有专门的医疗设备可用。
- **核心目标**: 提供一个实时数据合成平台，可视化鉴定对象数量，识别高峰期，并按技术复杂性对案件进行分类。
- **成功指标**: 鉴定对象等待时间减少 20%，部门工作量实现 100% 可视化。

## 2. 核心功能契约
1. **时间序列数量分析 (Temporal Volume Analytics)**:
   - 动态折线图/柱状图，展示每日和每月的鉴定对象数量。
   - 识别法医请求的季节性趋势。
2. **伤害分布映射 (Injury Distribution Mapping)**:
   - 基于“技术鉴定类别”（如交通伤害、临床过失、职业残疾）的鉴定对象视觉细分。
   - 采用饼图或环形图展示占比。
3. **案件状态流转 (Case Status Flow)**:
   - 交互式管道视图，展示鉴定对象从“初始登记”到“体格检查”再到“最终报告发布”的流转过程。
   - 漏斗图或桑基图形式呈现转化与积压节点。
4. **鉴定时间线预估器 (Appraisal Timeline Estimator)**:
   - 交互式微型工具。
   - 输入：当前鉴定对象数量、案件复杂性。
   - 输出：AI 计算的当前队列预计完成日期。

## 3. 内容意图地图 (Content Intent Map)
- **Header**: 品牌标识 (ForensicAppraise)，全局时间筛选器，当前系统状态概览。
- **Hero/Overview Metrics**: 核心 KPI 卡片（今日新增案件、当前积压、平均等待时间）。
- **Main Dashboard Area**:
  - 左侧/核心区：时间序列数量分析图表（折线/柱状结合）。
  - 右侧/次要区：伤害分布映射（环形图）。
- **Pipeline Section**: 案件状态流转可视化，包含各阶段的实时数字。
- **Interactive Widget**: 鉴定时间线预估器，放置在侧边栏或底部显眼位置，提供即时计算反馈。

## 4. 交互与状态定义
- **导航与筛选**: 顶部时间筛选器必须联动所有图表数据。
- **图表交互**: Hover 显示具体数值，点击图例可隐藏/显示特定类别。
- **预估器交互**: 表单输入后即时计算（或带 loading 动画后显示结果），并在页面内平滑展示预估日期。
