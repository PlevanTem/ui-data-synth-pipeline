# ClarityMesh 协同工作台 PRD

## 一句话定义
这个产品帮助跨职能项目团队在高频多源信息协作场景下解决信息过载与上下文割裂问题，让他们能在同一事实底座上快速协同决策并持续推进执行。

## 推理记录

### 用户与场景分析
- 目标用户并非单一角色，而是“决策发起者（项目经理）+执行协调者（运营/区域负责人）+审阅者（管理层）”的复合协作群体。
- 典型触发场景：晨会前风险盘点、突发事件响应、跨区域资源调度、周/月度复盘。
- 显性痛点：信息在白板、聊天、地图、报表之间分散；切换成本高；状态反馈碎片化。
- 隐性痛点：用户对“现在该看什么”缺少优先级引导，安全信号弱导致敏感沟通不放心，异常恢复路径不清晰导致焦虑。
- 用户真正目标不是“多几个模块”，而是“在复杂信息中更快形成可执行结论并推进行动”。

### 核心问题定义
- 该产品需要在高信息密度和高交互频率下，提供一个跨模块一致的“聚焦-协作-执行-追踪”闭环。
- 需求中包含新拟态风格约束，因此必须在“视觉宁静感”与“高密度可读性”间取得平衡。

### 实体与功能推导
#### 实体清单（核心）
- Workspace：承载成员、权限、时区与安全级别。
- WhiteboardBoard：协作画布与决策沉淀容器。
- ChatChannel/Message：加密沟通主链路与状态反馈主体。
- ReportTemplate/ReportRun：自动化洞察生成与推送执行。
- GeoFeed/GeoEvent/HeatmapLayer：地理态势与风险识别输入。
- DecisionSnapshot：跨模块证据聚合后的决策结论。

#### 功能点清单
**显性功能**
1. 实时白板共创（多人presence、撤销/重做、白板-消息互链）
2. 端到端加密聊天（线程、送达/已读、失败重试）
3. 报表自动化配置（模板、频率、对象、执行日志）
4. 地理追踪与热力图（对象定位、时间窗口、区域筛选）
5. 聚焦控制台（跨模块筛选、搜索、排序、决策快照）

**隐性功能**
1. 四大核心区的 loading/empty/error/retry 完整状态体系
2. 跨模块状态同步与可恢复流程
3. 新拟态一致性 token 系统（含主题切换可读性）
4. 页面内部交互完整性（导航、联动、表单、模态、动画编排）

#### 数据交互清单
- 用户触发：白板改动、消息发送、筛选搜索、报表配置、快照生成。
- 系统触发：地理流实时刷新、定时报表异步执行、通知派发。
- 依赖关系：鉴权→建立订阅→实时同步；模板配置完成→定时任务执行；筛选变化→多模块联动刷新。

#### 功能架构
- Live Collaboration Core
- Secure Messaging
- Insight Automation
- Geo Intelligence
- Attention Orchestration

模块依赖不是串行，而是围绕统一状态层并行联动；其中 Attention Orchestration 负责降噪与优先级排序，是“解决信息过载”的核心机制。

### 非功能需求推导
- 性能感知：关键动作 100-300ms 内可见反馈；实时视图以“稳定流畅”为优先。
- 视觉信任：需要 premium professional 观感，安全状态必须可被感知。
- 交互密度：高密度 + 多线程并发，必须提供聚焦与分层。
- 情绪目标：从“焦虑和混乱”转为“平静且可控”。

### 取舍说明
- M 类强调“协作主链路 + 边界状态 + 一致性 + 交互完整性”，因为它们直接决定是否真正解决信息过载。
- S 类保留更高表现力与效率增强（生成式视觉、多端连续性、提醒编排）；允许降级但不应缺席。
- X 类排除社交广场与支付闭环，原因是与核心目标无关，且会引入额外合规与复杂度噪音。

## 执行契约摘要
- Must Deliver（M01-M08）：白板实时协作、加密消息、自动报表、地理热力、聚焦控制台、完整状态系统、新拟态一致性、页面交互完整性。
- Should Deliver（S01-S03）：生成式视觉增强、多端连续性、提醒编排。
- Excluded（X01-X02）：对外社交分享、电商支付闭环。

## 设计约束
- 必须采用新拟态软UI风格，但避免“重阴影低对比”导致的可读性问题。
- 高信息密度下需要清晰层级、明确聚焦路径和跨模块一致动效节奏。

## 技术约束
- 前端交付必须是 TypeScript 多文件工程。
- 需支持实时模拟数据流、跨组件状态管理和动效降级策略。

## 边界情况
- 低性能设备下需自动降低视觉层复杂度，保留核心信息可用性。
- 网络抖动时必须提供离线/重试反馈，避免用户误判操作是否成功。
- 多角色并发编辑需要冲突可视化提示，避免“静默覆盖”。
