# AgriFlow Command - Design Brief

## 核心视觉方向
- 方向：`GeoPulse Tech Field`
- 气质：高科技、冷静、精准、可控
- 主色基调：蓝黑冷色深背景 + 电蓝信息高亮 + 琥珀告警强调
- 视觉母题：流场、脉冲、网格、地图热力、节点连接

## 布局策略
- Hero 先给价值与指标，再落到操作入口（产品演示、预约演示）。
- 中段采用“图表分析 -> 地图追踪 -> 工作流编排”连续决策流。
- 末段放成效证明与 CTA 表单，形成转化闭环。
- 移动端改为分段堆叠，保留筛选与 CTA 的固定可见性。

## 页面内部交互完整清单
- 导航：桌面锚点滚动；移动端抽屉菜单开合与平滑滚动。
- 筛选联动：时间范围、区域选择会同步影响图表数据、地图热度和 KPI。
- 图表交互：hover 显示读数，切换筛选有重绘动画与摘要数值变化。
- 地图联动：点击资源点后详情面板更新，图表切换为该对象数据视图。
- 工作流联动：拖拽节点、添加自定义节点、发布流程后触发全局 toast。
- 表单流程：字段校验、提交 loading、成功/失败反馈、可重试。
- 边界状态：loading/empty/error 三态必须在核心数据区可见。

## 动画与表现边界
- 动画节奏：微交互 150-250ms，区块过渡 250-450ms。
- 进入动画：按区块顺序错峰，不允许所有元素同时入场。
- 减弱动效：遵循 `prefers-reduced-motion`，流场背景降级为静态渐变。
- 禁止项：无业务语义的炫光/漂浮物；影响可读性的高频背景闪烁。

## Generative 视觉层实现指南
- Primary：Canvas `flow-field` 背景，低对比度、低速漂移，代表系统运行态。
- Secondary：SVG 图表 `path morph`，响应筛选变化做柔和插值过渡。
- Tertiary：地图热力脉冲，按风险等级映射半径/透明度/频率。
- 参数建议：
  - 粒子密度：`0.00008 - 0.00016 * viewportArea`
  - 噪声步进：`0.002 - 0.005`
  - 背景透明度：`0.18 - 0.32`
  - 热点脉冲周期：`1200ms - 2200ms`

## 组件气质
- 卡片：低反差玻璃感 + 清晰边框，重点状态有蓝色描边。
- 按钮：主 CTA 强对比实底，次 CTA 描边态。
- 表单：强调结构化、可信与可恢复，不做营销式夸张反馈。

## 前端禁止事项
- 禁止静态占位图代替图表交互。
- 禁止地图与侧栏断联。
- 禁止只做样式，不做真实筛选/状态流转。
# AgriFlow Command Design Brief

## 核心视觉方向
采用 `GeoPulse Tech Field`：蓝黑冷色为主，空间层级分为背景流场层、中景数据层、前景交互层。整体风格强调“专业指挥中枢”而非消费级炫技。

## 布局策略
- 顶部导航 + 页面分区锚点（Overview / Workflow / Geo / Proof / CTA）。
- 主内容采用 desktop 三模块联动（图表区、工作流区、地图区），mobile 转为分段切换。
- CTA 与关键警报保持高可见权重，避免被特效层淹没。

## 页面内部交互完整清单（必须实现）
1. 导航锚点点击平滑滚动，移动端抽屉导航可开关。
2. 筛选器变化后：图表重算、地图热度更新、告警列表重排。
3. 选择某区域卡片后：地图 zoom 到区域、工作流建议节点高亮。
4. 在工作流中新增自定义节点后：模拟执行结果更新到 KPI 卡片。
5. CTA 表单提交触发全局 toast，并在成功后重置字段。
6. 所有关键模块具备 loading / empty / error 态并可恢复。

## Generative 视觉层实现指南
- 主算法：Canvas `flow-field`（噪声驱动粒子），速度范围 `0.08-0.22`，密度移动端降至桌面的 `45-60%`。
- 次级算法：SVG path morph + dashoffset 轨迹动画，周期 `1.2s-2.4s`。
- 热力脉冲：基于数据阈值驱动 alpha 和 blur，禁止固定频率无限闪烁。
- 美学目标：冷静、克制、可控，表现“数据在流动而系统在掌控”。

## 禁止事项
- 禁止默认模板化 hero（三卡片+泛渐变）。
- 禁止把地图、图表、工作流做成互不联动的展示摆件。
- 禁止持续高频动画（需遵守 reduced-motion 与阅读优先）。
