# 创新设计模式指南

三种创新框架，各自生成差异化的设计提案方向。每种模式产出 2-3 个提案。

---

## 探索式创新（Exploratory Innovation）

**核心逻辑：** 突破类别边界，将不相关领域的原理、材料或形态迁移到当前问题。

**触发问题：**
- 这个对象在完全不同的领域（自然界/宇宙/显微世界）中的类比是什么？
- 如果材质/尺度/时间维度被极端化（极小/极大/极慢/极快），会变成什么？
- 这个功能如果在完全对立的语境（水下/太空/石器时代）中实现，形态是什么？

**发散轴：**
| 探索轴 | 问题模板 | 示例 |
|-------|---------|------|
| 跨界类比 | "这像[自然形态]" | 椅子 → 蘑菇菌盖的承重结构 |
| 尺度跳变 | "放大100倍/缩小到微观" | 包包 → 放大的细胞器形态 |
| 时间穿越 | "在[历史时期/未来]如何存在" | 灯 → 10000年后的生物发光体 |
| 系统借鉴 | "从[其他系统]借用运作逻辑" | 椅子 → 借用云的漂浮物理 |
| 极端假设 | "如果没有[核心属性]会怎样" | 透明的墙/无形的衣服 |

**输出格式：**
```
探索方向 [N]：[方向名称]
- 灵感来源：[跨界参照]
- 核心概念：[一句话描述]
- 关键视觉特征：[3-5个视觉词]
- 适合风格：[艺术风格方向]
```

---

## 组合式创新（Combinatorial Innovation）

**核心逻辑：** 将两个或多个不相关的已知事物进行有意义的融合，产生"1+1>2"的新形态。

**组合矩阵框架：**

| 组合维度A | × | 组合维度B | = 新概念 |
|---------|---|---------|---------|
| 功能对象 | × | 自然生物 | 仿生产品 |
| 传统工艺 | × | 数字技术 | 新工艺 |
| 建筑空间 | × | 服装构造 | 穿戴建筑 |
| 文化符号 | × | 当代材料 | 文化再造 |
| 情绪/感觉 | × | 具体物体 | 情感具象 |

**触发问题：**
- 哪两件毫不相关的事物，如果合体会产生有趣的张力？
- 传统的[A]和现代的[B]，最有创意的交叉点在哪里？
- 如果把[功能X]的解决逻辑套用在[对象Y]上，会产生什么？

**组合强度分级：**
- **浅层组合**：视觉元素叠加（形态借用、图案融合）
- **中层组合**：材质/工艺混搭（传统材料×数字工艺）
- **深层组合**：功能逻辑融合（A的运作方式解决B的问题）

**输出格式：**
```
组合提案 [N]：[A] × [B]
- 组合逻辑：[浅层/中层/深层]
- 新概念描述：[产生了什么新事物]
- 视觉关键词：[3-5个词]
- 张力所在：[有趣的矛盾或惊喜点]
```

---

## 迭代式创新（Iterative Innovation）

**核心逻辑：** 在原有形态或已有方案基础上，通过系统性变异（放大/减弱/替换/重组）产生进化的新方案。

**SCAMPER 变异框架：**

| 操作 | 英文 | 触发问题 | 示例 |
|-----|------|---------|------|
| **S**ubstitute | 替换 | 如果把[核心材质/组件]换成[X]？ | 木椅 → 全冰椅 |
| **C**ombine | 合并 | 如果把[A功能]和[B功能]合并？ | 桌子+植物盆 |
| **A**dapt | 适应 | 哪个其他领域的解法可以借用？ | 拉链 → 建筑开口 |
| **M**agnify/Modify | 放大/修改 | 如果把[某特征]放大10倍或完全去除？ | 超大扣子 |
| **P**ut to other uses | 另作他用 | 这个形态可以解决什么意外的问题？ | 雨伞→隔断屏风 |
| **E**liminate | 删减 | 去掉哪个"必要"元素后更有力？ | 无腿的椅子 |
| **R**earrange/Reverse | 重排/反转 | 如果颠倒或重新排列逻辑结构？ | 由内而外的建筑 |

**迭代层次：**
- **微迭代**：细节优化（比例调整、材质替换、颜色变奏）
- **中迭代**：结构重组（组件重排、功能重新分配）
- **宏迭代**：概念反转（核心假设推翻、颠覆性重构）

**输出格式：**
```
迭代方案 [N]：[操作类型] + [变异描述]
- 起点：[参照的已知形态]
- 变异操作：[SCAMPER中的哪种]
- 产生结果：[演变后的新形态]
- 视觉关键词：[3-5个词]
- 层次：[微/中/宏迭代]
```

---

## 三种模式选择指南

| 场景 | 推荐模式 | 原因 |
|-----|---------|------|
| 需要颠覆性突破、品类创新 | 探索式 | 最大跨度，意外感最强 |
| 需要融合两种已有优势 | 组合式 | 清晰逻辑，可落地 |
| 在已有方向上精进 | 迭代式 | 延续性强，风险可控 |
| 一次产出多样方向 | 三种各出1-2个 | 覆盖全谱 |
