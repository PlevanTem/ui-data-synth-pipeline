# 设计研究与风格探索工作流

这个 skill 现在的主要定位不是“为 AI 生图生成 prompt”，而是帮助设计师或 pipeline 在早期阶段完成：

- 外部优秀网站与趋势参考搜寻
- 风格与审美信号判断
- 多方向发散
- 视觉语法与体验方向提炼
- 反模板化风险识别

在 `web-design-pipeline` 中，应把它当成 **研究引擎** 使用，而不是图像生成 orchestrator。

## 适用场景

优先用于：

- 网站、landing page、dashboard、web app、品牌官网、叙事型页面
- 需要参考最新优秀设计案例与趋势
- 需要做方向发散，而不是直接套模板
- 需要提炼“视觉母语”“惊艳点”“项目专属气质”

不要优先用于：

- 单纯输出图像生成 prompt
- 需要逐步陪聊确认的创意咨询流程
- 与网页体验无关的独立插画/角色/包装生成任务

## 当前项目中的使用方式

在 `web-design-pipeline` 里，主要借用这四类能力：

1. **趋势扫描**
   - 利用高质量平台和来源，搜集最新优秀参考案例

2. **风格发散**
   - 不直接落到一种风格，而是先探索多个可行方向

3. **审美信号判断**
   - 判断某种视觉路线在传递什么信号
   - 判断它是跟随、推进还是逆势
   - 判断它容易落入什么俗套

4. **视觉语法提炼**
   - 提炼项目专属的构图、材质、速度感、动效语言和过渡方式

## 核心流程

### STEP 1：问题 framing

先从上游输入中提炼：

- 产品类型
- 行业语境
- 目标用户
- 关键情绪
- 交互强度
- 视觉表达强度
- 这次最可能的“惊艳点”

这里的目标不是确认“设计对象比例”，而是明确研究问题。

### STEP 2：趋势扫描

读取 `references/trend-sources.md`。

根据项目目标，选择一个主轨道或多个混合轨道：

- **高端品牌轨**
  - 适合高端品牌站、营销站、空间感、材质感、精致叙事
- **商业插画轨**
  - 适合需要强情绪、人物/图形叙事、柔和品牌表达
- **新视觉实验轨**
  - 适合需要前沿感、实验网页、视觉识别度、数字艺术感

执行要求：

- 做 4-6 次高质量 WebSearch
- 优先搜优秀网站、设计平台、奖项、编辑型灵感库
- 不要搜泛泛教程文
- 每条参考都要提炼“为什么值得看”，而不是只贴链接

输出应至少回答：

- 当前主流方向是什么
- 哪些新兴信号值得关注
- 哪些案例与当前项目最相关
- 哪些方向虽然流行，但不适合本项目

### STEP 3：审美信号判断

读取：

- `references/art-styles.md`
- `references/aesthetic-signals.md`

对每个候选方向回答：

1. **它在传递什么信号**
2. **它是跟随、推进还是逆势**
3. **它的执行陷阱是什么**

这一步的目标不是“挑一个好看的风格”，而是判断：

- 这个方向和项目语义匹不匹配
- 这个方向是不是只是流行，但不够对题
- 这个方向会不会把项目做成模板拼贴

### STEP 4：方向发散

至少探索 3 个方向：

- 一个稳妥高完成度方向
- 一个主推方向
- 一个偏实验方向

每个方向都要写清楚：

- 风格关键词
- 视觉信号来源
- 构图与层次思路
- 材质与光感特征
- 交互语言
- 动效语言
- 是否需要生成式视觉层 / 3D / 插图系统
- 为什么可能不选

### STEP 5：视觉语法提炼

在选定主方向后，提炼项目专属视觉语法：

- `composition_language`
- `material_language`
- `motion_language`
- `icon_illustration_language`
- `transition_language`

你要回答：

- 这个项目的“视觉母语”是什么
- 用户操作后页面应该发生什么有意义的变化
- 哪些模块承担体验锋面
- 哪些套路必须规避

## 输出要求

这个 skill 不再默认输出生图 prompt。

它更适合输出给下游 agent 的研究性结论，例如：

- 趋势洞察摘要
- 方向对比结论
- 视觉信号分析
- 反模板化清单
- 视觉语法要点
- 可转入 `experience_blueprint.json` 的素材

## 当前项目中的明确约束

如果你处于 `web-design-pipeline` 上下文：

- 不要输出图像生成 prompt 作为默认结果
- 不要用逐步等待用户确认的对话流程拖慢 pipeline
- 不要把“是否流行”当成“是否适合”
- 不要只给风格词，不解释背后的体验意义
- 不要只给漂亮参考，不提炼可执行结论

## 成功标准

当 Designer 或 pipeline 使用这个 skill 后，应该能得到：

- 一组高质量外部参考，不是泛搜结果
- 经过筛选的方向候选，不是随机灵感拼贴
- 可解释的审美判断，不是“这个比较高级”
- 可转入体验蓝图的视觉语法线索
- 明确的反模板化提醒
