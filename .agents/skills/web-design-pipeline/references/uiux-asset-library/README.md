# UI/UX Asset Library

这里不是案例成品仓库，而是设计能力沉淀区。

## 目标

把每次 case 中可泛化的 UI/UX 结论沉淀下来，减少重复思考，同时避免输出越来越像同一套模板。

## 子目录说明

- `trend-notes/`
  - 记录某类领域、情绪或交互趋势
- `style-recipes/`
  - 记录可复用风格配方
- `palette-strategies/`
  - 记录配色体系和适用语境
- `motion-patterns/`
  - 记录动效模式、适用场景和性能风险
- `anti-patterns.md`
  - 记录常见同质化问题和设计误区

## 沉淀规则

- 只沉淀“可复用规律”，不直接复制某个 case 的最终文案
- 每条资产都写清楚：
  - 适用场景
  - 不适用场景
  - 风险与反模式
- 如果某条经验还不足以泛化，不要入库

## 命名建议

使用短英文 slug：

- `b2b-dashboard-density.md`
- `warm-editorial-commerce.md`
- `soft-tech-motion-patterns.md`
