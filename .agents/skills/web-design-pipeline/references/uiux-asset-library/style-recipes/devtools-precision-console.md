# Devtools Precision Console

## 适用场景

- 高密度开发者工具
- 性能分析台
- 日志 / trace / profiling 工作台
- 需要暗黑模式长时间使用的工程类产品

## 核心特征

- 深石墨底色，不做大面积氛围渐变
- 通过细边框、局部底色、刻度线和行内高亮建立层级
- 让时间线、表格、列表成为主视觉，而不是 KPI 卡片模板
- 强调色只承担语义，不承担氛围

## 推荐做法

- 左侧导航 + 顶栏过滤 + 中央主分析区 + 右侧详情栏
- 时间线优先 Canvas
- 表格优先高对比、紧凑行高、Mono 数字对齐
- 查询面板做成证据驱动的分析面板，而不是聊天界面

## 可借鉴的新拟态范围

- 仅用于小控件的按压感和聚焦态
- 不用于大面板、指标卡和数据容器

## 不适用场景

- 品牌营销官网
- 强叙事型产品页
- 需要温暖情绪化氛围的消费类产品

## 反模式

- 紫蓝科技渐变默认铺底
- 满屏玻璃卡片
- 首页 KPI 卡 + 英雄区模板
- 用背景噪声和发光制造“高级感”
