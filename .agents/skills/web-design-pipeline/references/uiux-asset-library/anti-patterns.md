# Anti-Patterns

这个文件记录网站生成过程中常见的同质化和低质量设计问题。

## 视觉同质化

- 默认紫蓝科技渐变，和领域语义无关
- 不分场景地铺满玻璃拟态卡片
- 总是"居中标题 + 副标题 + 3 张卡片 + CTA"
- 过度使用发光、模糊、噪声背景来制造"高级感"
- **MagicUI 默认样式直接上线**：Globe 用默认紫蓝色弧线、BentoGrid 用默认 4 格布局不做定制、Orbiting Circles + Animated Beam + Globe 三件套同时出现——这是 2025-2026 年最高频的"一眼 MagicUI 模板"特征，必须深度定制颜色、图标、布局后才能使用
- **动效组件库堆叠滥用**：在同一页面同时铺开多个竞争性背景动效（如 ReactBits Aurora + MagicUI Particles + Flickering Grid），或整页每个区块都有不同动效库的组件，动效互相竞争注意力，丧失视觉层次感

## 信息架构问题

- 英雄区视觉很满，但用户不知道下一步做什么
- Dashboard 信息堆积，没有视觉优先级
- CTA 太多，导致主转化路径不清楚

## 交互问题

- hover 很炫但点击后没有价值
- 动效只追求存在感，不服务于状态切换
- 背景特效抢走正文注意力
- **文字动效过度使用**：整页所有文字都有 SplitText / BlurFade / TextPressure 等动效，失去注意力引导；应只在 hero 标题和 1-2 个关键区块使用高强度文字动效

## 技术实现问题

- 为简单页面选择过重技术栈
- 引入 WebGL 或 p5.js 却没有降级方案
- 页面可运行性差，却用截图或描述掩盖问题
- **引入动效组件库却不做 MCP 集成**：手动复制粘贴 MagicUI/ReactBits 组件代码而不通过 CLI/MCP 安装，导致组件版本不可追踪、依赖残缺、缺失必要的 peer dependencies

## 资产沉淀问题

- 把某次案例成品直接复制进资产库
- 把一次性的潮流元素误当成长期可复用方法
- 只记录"喜欢什么"，不记录"为什么"和"不适合什么"

## 使用方式

每次生成前，先快速检查这份清单。

每次生成后，若发现新的重复问题或低质量套路，及时补充。
