# Blue Black Wayfinding

## 适用场景
- 需要高科技气质但仍强调可信度的旅行、导航、出行产品
- 需要在深色模式中同时容纳流程、地图、热点和提醒信息的界面

## 配色策略
- 主背景：海军蓝黑与石墨蓝，确保长期阅读稳定。
- 功能高亮：电青或薄荷，用于路径、热点、焦点和主 CTA。
- 奖励与提醒：少量琥珀或暖橙，只在积分、提醒、关键收益上出现。
- 风险状态：偏红但降低饱和度，避免全站进入告警情绪。

## 不适用场景
- 温暖治愈或自然疗愈导向的产品
- 需要大面积高亮色建立品牌亲和力的儿童或家庭产品

## 风险点
- 如果蓝黑层级不够，会让所有区块糊成一片。
- 如果高亮色使用过多，会立刻滑向廉价赛博风。
