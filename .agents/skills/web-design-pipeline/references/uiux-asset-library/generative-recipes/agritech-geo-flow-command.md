# AgriTech Geo-Flow Command

- `style_keywords`: high-tech-calm, geo-command, dark-field, precision-glow, data-theater
- `interaction_level`: immersive
- `visual_primitives`: grid, field, pulse, heat, path, panel-depth
- `motion_primitives`: drift, pulse, filter-sync, route-reveal, staged-enter
- `generative_primitives`: noise, flow, particles, heat-diffusion
- `implementation_hints`: Canvas flow-field background + SVG chart tween + map heat overlay; use throttle and reduced-motion fallback
- `uiuxmax_domains`: style,color,typography,ux,chart,stack
- `suitable_stacks`: react, nextjs, vue
- `avoid_patterns`: over-neon, full-screen glassmorphism, non-semantic decorative particles

## 适用场景
- 需要实时态势感与空间调度语义的农业/物流/应急指挥类产品。

## 不适用场景
- 以温暖生活方式叙事为核心的轻内容品牌站。

## 风险点
- 动画同频过多会导致认知噪声；必须分层控制节奏与亮度。
